# PR Review Agent

## Challenge

Build an agentic system capable of reviewing pull requests in a software codebase.

Your system should be able to handle:

* receiving a pull request containing code changes
* understanding the intent of the change
* reviewing the changed code for potential issues
* identifying meaningful bugs, risks, or missing tests
* generating actionable review comments
* posting the review back to GitHub

You have full creative control to decide how it should work, and may use any tools available.

You have access to an example repository which you'll use as the test case for your agent.

## Part 1: Architecture — 45 minutes

Consider the problem and design your system architecture.

Please feel free to ask questions, do research, and use AI or other tools freely.

Show how you think through the problem and ultimately create the design document you'll use in Part 2.

## Part 2: Implementation — 45 minutes

Use Claude to implement your architecture from Part 1.

Test and iterate your system using pull requests against the example repository.

When you're ready, a previously unseen pull request will be provided for a final test.
